Project Overview: It is a billing management software created using different modules of Python. Its GUI created using tkinter, turtle. datetime and random modules are also used. For backend the Python module sqlite3 is used which stores information DB Browser.
The UI provides Categories and Sub-categories of the product bought, returns the corresponding price and calculates subtotal, tax, discount, and grand total. The bill is printed in the textarea provided.
This software also handles exceptions and prevents clearing bill if not saved.
