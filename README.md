# Billing Software
### Project Overview:
It is a billing management software created using different modules of **Python**. GUI created using *tkinter*, *turtle*, *datetime* and *random* modules.<br><br>
For backend the Python module *sqlite3* is used which stores information **DB Browser**.
The Software provides Categories and Sub-categories of the product bought, returns the corresponding price and calculates subtotal, tax, discount, and grand total. The bill is printed in the textarea provided.
This software also handles exceptions and prevents clearing bill if not saved.

--- 
### Installations Required:
- Python Interpreter
- DB Browser for SQLite
